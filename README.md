# Artificial Eyes

Artificial Eyes is an AI-assisted assistive technology prototype for visually impaired users.
It combines a project website, Android APK resources, product images, documentation, and ESP32 hardware source materials.

[Live Website](https://artificialeyes.ddns.net/) | [Download APK](assets/build/artificial_eyes.apk)

## Overview

Artificial Eyes focuses on everyday support scenarios:

- movement assistance through embedded hardware
- mobile app resources for AI-assisted features
- voice commands and audio responses
- project documentation and source materials
- a public website for presenting the prototype

## Repository Contents

| Path | Purpose |
| --- | --- |
| `index.html` | Main static website |
| `assets/build/artificial_eyes.apk` | Android APK build |
| `assets/images/` | Product images, QR code, and source screenshots |
| `docs/source-code/Source_HW.ino` | ESP32 hardware control source |
| `docs/artificial-eyes-description.docx` | Project description document |

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

```bash
npx serve .
```
